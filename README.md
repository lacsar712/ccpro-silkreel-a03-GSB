# SilkReel-01 · 江口缫丝坞

缫丝盆环状作业台。登录后看到的是沿汤池围成一圈的盆位，点盆登记汤温并改状态——不是侧栏双列表 CRUD。

## 技术栈

| 层 | 技术 |
| --- | --- |
| Web API | Quart（异步 Flask 族）· Hypercorn |
| 结构 | `repositories.py` 仓储 + `services.py` 门槛，路由不直接拼 SQL |
| 数据 | SQLAlchemy 2 async · asyncpg · PostgreSQL 15 |
| 前端 | Preact 10 · Vite |
| 部署 | Docker Compose |

## 业务规则

- 盆状态不可标成「已缫完」，除非该盆**最近一条**汤温记录落在 **38～42℃**；此判定只看汤温，与茧粒差无关。
- 「浸茧」改成「缫丝中」时，读取环上相邻盆（`ring_index` 首尾相接）：若邻盆有正在缫丝中的，本盆茧粒数与之相差**不得超过 120 粒**（严格大于 120 才挡，差恰好 120 放行）；没有缫丝中邻盆则不比较。规则在 `backend/app/services.py`。
- 改态在单事务内对同坞盆行 `SELECT … FOR UPDATE` 加锁并校验，两名工同时抢改同一浸茧盆时只有一笔入库，另一笔得到 409。
- 顶栏可在「环盆作业台」与只读「茧粒台」之间切换；茧粒台列出各坞各盆茧粒数及与**最近缫丝中盆**的环距差值（超过 120 标红），可按坞筛选。

## 种子数据

江口缫丝坞为三口环盆：甲 缫丝中 400 粒；乙 浸茧 520 粒（差 120，可改成缫丝中）；丙 浸茧 600 粒（差 200，必被挡）。另有西湾缫丝坞用于按坞筛选与已缫完汤温场景。种子幂等，旧卷缺 `cocoon_count` 列时启动自动补列并对账旧盆。
